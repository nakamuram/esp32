# esp32

ESP32 でセンサーデータを取得し、AWS を使って可視化するまでを一通りやってみるプロジェクト。

写真も多めに掲載して、**初心者向けのチュートリアル的な技術ページ**になれば良いと考えている。
（私のスキルで可能かは微妙）
